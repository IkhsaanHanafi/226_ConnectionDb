# 226_ConnectionDb

Program Express JS untuk koneksi ke database PostgreSQL (`mahasiswa`, tabel `biodata`).

## Tabel biodata

| Kolom | Keterangan |
|-------|------------|
| id    | primary key |
| nama  | nama mahasiswa |
| nim   | NIM |
| kelas | kelas |
